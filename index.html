☁NO WEIRD FINE PRINT

Privacy, plainly.

Chat content is peer-to-peer. Messages and images travel between the two browsers over a WebRTC data channel. Afterglow does not upload chat content to its website host or a chat database. The public PeerJS signaling service helps the browsers find each other; it handles connection setup metadata, not the chat messages.

When does it disappear? If either person leaves or the connection breaks, the room ends and the interface clears both views. Active content exists in browser memory while the room is open; a crash or disconnection can end the chat unexpectedly.

Save means save to your device. The Save chat button downloads a JSON export to your device. That file can outlive the room, and it is your responsibility to protect or delete it.

Network caveat. WebRTC works directly on many networks, but strict school, office, or mobile networks can block peer connections. This version has no TURN relay fallback, so some connections may fail. Other participants can also copy or screenshot content. Use a trusted network for private conversations.
